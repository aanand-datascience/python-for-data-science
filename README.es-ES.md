## Descripción del Proyecto

Este repositorio contiene notas estructuradas y cuadernos de práctica sobre bibliotecas importantes de Python utilizadas en Ciencia de Datos y Análisis de Datos.

El objetivo de este repositorio es construir una base sólida en las bibliotecas de Python comúnmente utilizadas en proyectos reales de ciencia de datos.

---

## Bibliotecas Cubiertas

- NumPy
- Pandas
- Matplotlib

Cada cuaderno contiene explicaciones, ejemplos e implementaciones prácticas de código.

---

## Estructura del Repositorio

NumPy_basic_info.ipynb → Introducción a NumPy  

NumPy_phase-1.ipynb → Conceptos básicos de NumPy y arrays  

NumPy_phase-2.ipynb → Indexación y operaciones con arrays  

NumPy_phase-3.ipynb → Operaciones matemáticas  

NumPy_phase-4.ipynb → Conceptos avanzados de NumPy  

Pandas.ipynb → Análisis de datos usando Pandas  

Matplotlib.ipynb → Visualización de datos usando Matplotlib

## Propósito

- Aprender bibliotecas de Python utilizadas en Ciencia de Datos  
- Practicar conceptos importantes
